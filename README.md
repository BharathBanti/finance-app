# 🚀 Tailwind CSS Responsive Landing Page

A modern, responsive landing page built using **Tailwind CSS** and **vanilla JavaScript**.  
This project demonstrates clean UI design, custom Tailwind plugins, and interactive frontend behavior, making it suitable for portfolio and real-world frontend use cases.


## ✨ Features

- 📱 Fully responsive design (mobile-first)
- 🍔 Mobile hamburger navigation menu
- 🧩 Custom Tailwind CSS plugins and components
- 💬 Interactive testimonials section
- 💳 Animated pricing cards with toggle functionality
- ⚡ Clean and optimized production-ready CSS


## 🛠️ Tech Stack

- **HTML5**
- **Tailwind CSS**
- **JavaScript (ES6)**

> Tailwind CSS is precompiled into a single `output.css` file for deployment.


## 📂 Project Structure

├── index.html #Main HTML file

├── input.css #Custom styles (utilities, components, etc)

├── output.css #Compiled Tailwind CSS (production-ready)

├── script.js #JavaScript for UI interactions

├── media/ #Images and static assets (if any)

└── README.md
